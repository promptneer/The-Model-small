1它是什么

「老仓管」把一件事拆成两半，各干各的，谁也别越界：

脑子（小模型）

负责听懂你的话、判断你想干什么、把要求翻成标准指令。它不亲自干活，只动嘴。

手脚（脚本程序）

负责真正的体力活：翻文件夹、查台账、登记修改。动作快、结果准、绝不瞎编。

翻译官（调度器）

脑子说的话，翻译官先检查一遍：合法才执行，有错就拦下，出事能撤回。

好处：模型只管动脑子，所以显存占用小、速度够快；脚本只管干活，所以不会出现模型胡编路径、假报结果的情况。

2文件夹里都有什么

laocang-guan ← 系统主文件夹，以下都在它里面
├── 使用说明书.html ← 你现在看的这一页
├── main.py ← 大门口。启动它 = 打开老仓管
├── test_run.py ← 体检表。跑一遍=检查系统有没有毛病
├── seed_ledger.py ← 第一次用之前，先跑它给台账装点示例数据
├── requirements.txt ← 依赖清单（装模型工具时看它）
├── core ← 核心零件，别乱动，改坏了系统不干活
│   ├── brain.py ← 脑子：接各种小模型
│   ├── dsl_parser.py ← 翻译官·审稿：检查指令合不合法
│   ├── scheduler.py ← 翻译官·调度：安排干活、出错回滚
│   ├── registry.py ← 手脚登记簿：所有能干的事都登记在这
│   └── ledger.py ← 台账本：管资产数据、留操作记录
├── atoms ← 手脚们，一个文件一种本事
│   ├── file_find.py ← 找文件（按名字/类型/目录）
│   ├── ledger_query.py ← 查台账（总数/按名搜/最近记录）
│   ├── ledger_update.py ← 改台账（登记/修改/删除，能撤回）
│   └── system_info.py ← 看本机环境（显卡/内存/磁盘）
├── docs ← 三份技术说明书（给技术同事看的）
├── data ← 台账数据库文件（自动生成，别手动删）
└── …模型文件 ← 在 E:\mayue\_models\，下载好后自动使用
文件/文件夹一句话人话解释
main.py入口。运行它，就能跟老仓管对话。
test_run.py体检。运行它，15 项检查全过就说明系统是健康的。
seed_ledger.py首次使用前运行一次，给台账塞几条示例数据（叉车、手套之类的），方便你先试试。
core\brain.py大脑。负责接 Ollama / llama.cpp / 本地 GGUF 模型，决定用哪个脑子。
core\scheduler.py + dsl_parser.py翻译官。脑子的话先审再办，非法指令直接拦下，绝不瞎执行。
core\ledger.py台账本。资产数据都存在这里面（SQLite 数据库），每次操作都会留记录。
atoms\手脚。找文件、查台账、改台账、看环境，四样本事，一个文件一项。
docs\三份给技术同事看的说明书：架构、指令规范、部署教程。
data\台账数据库自动生成在这里，平时不用管。

经验之谈：日常你只需要碰 main.py（打开）、test_run.py（体检）、seed_ledger.py（首次初始化）。core 和 atoms 里的东西，除非技术同事要改功能，否则别动。

3怎么启动（照着做就行）

第一次使用，先给台账装示例数据 
python E:\mayue\laocang-guan\seed_ledger.py
打开老仓管（两行设置 + 一行启动） 
# 这两行告诉它用本地模型文件，直接复制粘贴
$env:LC_BRAIN="pyllama"; $env:LC_GGUF="E:\mayue\_models\qwen2.5-1.5b-instruct-q4_k_m.gguf"
python E:\mayue\laocang-guan\main.py

看到「大脑后端: pyllama」就成功了。首次启动等几秒（模型加载），之后每句话 3~8 秒回应。

体检（可选，想确认系统健康就跑） 
python E:\mayue\laocang-guan\test_run.py

正常结果：15 通过，0 失败。

4怎么跟它说话（就说人话，不用学指令）

直接打字，像跟仓库老师傅交代事情一样。它听懂后自己去查、去办、回来汇报。

你：查台账里有没有防静电手套
老仓管：查到 1 条：防静电手套 | 工具间-02柜 | 50 双
你：看一下仓库现在有多少资产
老仓管：台账共 12 项资产：工具×5、耗材×4、设备×2、文档×1
你：登记一台新叉车，放维修区，1 辆
老仓管：台账已更新：新叉车 已登记（维修区，1 辆）
你：系统环境怎么样
老仓管：GPU: NVIDIA GeForce GTX 1650 4GB | 内存剩余、磁盘剩余一并汇报

小命令（斜杠开头的快捷操作）

输入作用
/ledger把台账全部资产列出来
/stats台账统计（各类别数量）
/recent 5最近 5 条操作记录
/mode看当前用的是哪个大脑
/quit退出

提示：如果某句话它没听懂，会如实说「无法理解」，不会瞎猜着干。换个更直白的说法再问一次就行。

5它守的三条规矩（这套系统靠谱的原因）

听不懂就拦下，绝不瞎干

模型说人话、写乱码、提没登记过的要求？调度器直接拦下，一个动作都不执行。宁可拒绝，不猜着办。

要么全办成，要么全撤回

一次要求拆成好几步，如果做到一半出岔子，前面已经改的会自动撤销，台账回到原来的样子。

每次动手都留记录

谁在什么时候、做了哪步操作、成没成功，全部写进台账的审计记录，随时可查（/recent）。

7常见问题（三句话讲清）

打开后卡在「大脑调用失败」怎么办？

多半是模型文件没放对位置，或上一行 $env: 设置没生效。检查 E:\mayue\_models\ 里有没有 qwen2.5-1.5b-instruct-q4_k_m.gguf 这个文件（约 1GB），再把那两行设置重新粘贴一遍。

它说「模型输出的不是合法鸟语DSL」？

小模型偶尔走神，输出了一句人话而不是指令。这是安全机制在起作用——它拦下了，什么都没干。把需求说得更直白再问一次，基本就好了。

台账是空的 / 查不到东西？

先运行一次 seed_ledger.py 初始化示例数据。如果要录入自己的资产，直接对它说「登记XXX，放XX，X件」就行。

想要更快更强？

你的机器如果显卡够好（比如 RTX5060 8G），按 docs\03-部署与测试教程.md 的 A 路线装 Ollama + qwen2.5:3b，速度翻倍、理解更好，其他代码都不用动。

这些技术文档在哪？

docs\ 文件夹里三份：01 架构说明（给技术看的系统设计）、02 指令规范（鸟语DSL 的完整语法）、03 部署教程（装模型、启动、测试的详细步骤）。
