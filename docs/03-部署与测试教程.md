## A 路线 · RTX5060 8G（推荐）

### A1. 安装 Ollama

1. 下载安装：https://ollama.com/download （Windows 安装包，约 700MB）
   - 国内网络不通时，用镜像：`ollama-windows-amd64.zip` 从 GitHub 镜像站下载后解压，直接运行 `ollama.exe`
2. 安装完成后验证：

```powershell
ollama --version
ollama serve    # 若未自动启动服务，手动执行（保持窗口开着）
```

### A2. 拉取模型并验证

```powershell
ollama pull qwen2.5:3b          # 约 2.3GB（Q4 量化）
ollama list                     # 应看到 qwen2.5:3b
```

### A3. 启动老仓管

```powershell
cd E:\mayue\laocang-guan
python main.py                  # 自动探测到 Ollama → 使用 qwen2.5:3b
```

看到 `大脑后端: ollama` 即成功。

## B 路线 · GTX1650 4G（本测试机已实测通过）

### B1. 安装 llama-cpp-python

```powershell
pip install llama-cpp-python -i https://pypi.tuna.tsinghua.edu.cn/simple
# 如需 CUDA 加速（GPU 版）：
# pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
```

### B2. 下载模型 GGUF

```powershell
# 方式一：hf-mirror（国内快）
python E:\mayue\_setup\fetch_gguf.py
# 产物：E:\mayue\_models\qwen2.5-1.5b-instruct-q4_k_m.gguf（约 1.1GB）

# 方式二：手动下载
# https://hf-mirror.com/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf
```

### B3. 启动老仓管（pyllama 后端）

```powershell
cd E:\mayue\laocang-guan
$env:LC_BRAIN="pyllama"
$env:LC_GGUF="E:\mayue\_models\qwen2.5-1.5b-instruct-q4_k_m.gguf"
python main.py
```

看到 `大脑后端: pyllama` 即成功（首次加载模型约 2~10 秒）。

**本机实测记录（GTX1650 4G / CPU 推理 / 0.3.19）：**

| 指标 | 实测值 |
|---|---|
| 模型加载 | 2.3 s |
| 单次需求→DSL 生成 | 3~8 s |
| 端到端（需求→执行→汇报） | < 15 s |
| 内存占用 | ~2 GB |
| 验证结果 | 3/3 用例通过（含真实台账查询、系统信息） |

> 注意：若系统残留无效的 `CUDA_PATH` 环境变量（指向不存在的 CUDA Toolkit 目录），
> 会导致 llama_cpp 加载失败——老仓管已在代码层自动摘除该变量，无需手动处理。

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `大脑调用失败: <urlopen error ...>` | Ollama 服务未启动；或 `LC_OLLAMA_URL` 端口不对。执行 `ollama serve` |
| `模型输出的不是合法鸟语DSL` | 模型偶尔输出散文。**重说一遍需求**（更简洁/明确），或切到 `/dsl off` 再试；多次出现可降低温度 |
| `GPU: 未知` | 非 NVIDIA 机器或 nvidia-smi 不在 PATH，不影响其他功能 |
| 台账查不到 | 先 `python seed_ledger.py` 初始化示例资产 |
| 显存不足 | 换更小量化（Q4_K_M → Q4_0），或加 `-ngl` 分层限制（pyllama 模式可调 `n_gpu_layers`） |
| 模型推理慢 | 1.5B Q4 在 CPU 上约 5~15 tok/s，可接受；RTX5060 上 3B 约 30+ tok/s |

## 7. 环境变量一览

| 变量 | 默认 | 说明 |
|---|---|---|
| `LC_BRAIN` | 自动 | `ollama` / `llama` / `pyllama` / `mock` |
| `LC_OLLAMA_URL` | `http://127.0.0.1:11434` | Ollama API 地址 |
| `LC_MODEL` | `qwen2.5:3b` | Ollama 模型名 |
| `LC_LLAMA_URL` | `http://127.0.0.1:8080` | llama-server API 地址 |
| `LC_GGUF` | 空 | pyllama 模式的 GGUF 文件路径 |
